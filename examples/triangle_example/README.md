# GFVL Hello, triangle!
This is the GFVL example for the least amount of code to draw a triangle, instead of a 1000 or so lines of vulkan, it's only 90~ lines of C++ code.

## How to compile

- Build GFVL but add option COMPILE_TRIANGLE_EXAMPLE (or COMPILE_ALL_EXAMPLES to also compile every other example.)
- Compile the files as usual
- Compile the GLSL fragment and vertex shaders into SPIR-V (.spv) files. Make sure that they are in the same directory.
- Run the .exe, it should be in this directory.
