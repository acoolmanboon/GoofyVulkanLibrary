# GFVL Moon Example
This example is a simple procedurally-generated terrain resembling the moon or some generic rocky planet.
This uses the Perlin Noise library made by  Ryo Suzuki <reputeless@gmail.com>

***GFVL doesn't have that many features yet so this uses pretty much every feature available.***

## How to compile

- Build GFVL but add option COMPILE_MOON_EXAMPLE (or COMPILE_ALL_EXAMPLES to also compile every other example.)
- Compile the files as usual
- Compile the GLSL fragment and vertex shaders into SPIR-V (.spv) files. Make sure that they are in the same directory.
- Run the .exe, it should be in this directory.

## Controls
- **V** to fly
- **Escape** to unlock mouse
- **Left Shift** to run
- **Space** to move the light source to your position
- **WASD** or **ARROW KEYS** for movement
